# Shalom Rio — Landing Page

Remodelação do site para uma experiência vertical, moderna e responsiva.

## Estrutura

A página inicial (`/`) agora funciona como uma landing page contínua:

1. Hero / 30 anos
2. Sobre o Shalom no Rio
3. Experiência nos centros de evangelização
4. Eventos
5. Onde estamos
6. Notícias
7. Contato
8. Rodapé

As páginas detalhadas antigas continuam disponíveis nas rotas existentes, incluindo os centros de evangelização.

## Rodar

```bash
npm install
npm run dev
```

Para validar a produção:

```bash
npm run build
```
